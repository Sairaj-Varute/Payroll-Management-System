# Payroll Management System

A full-stack Payroll Management System built using Spring Boot, React.js, MySQL, and REST APIs.

## 🚀 Features

- Admin authentication
- Employee management
- Department management
- Attendance management
- Salary management
- Payment management
- Protected routes
- RESTful APIs
- MySQL database integration

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- CSS
- Vite

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- REST APIs
- Maven

### Database
- MySQL
